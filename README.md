# Векторный макет фактуры панельного дома для светильника 320×200 мм (ЛМДФ)

Лазерная гравировка фасада типовой панельной многоэтажки (хрущёвка/брежневка)
по приложенному образцу. Генерация полностью параметрическая — все размеры
задаются в миллиметрах в начале `scripts/generate_facade.py`.

## Файлы

| Файл | Назначение |
|---|---|
| `output/facade_panel_320x200.dxf` | **Основной файл для станка.** DXF R2010 (AC1024), единицы — миллиметры (`$INSUNITS=4`) |
| `output/facade_panel_320x200.eps` | EPS 3.0, координаты в мм, два RGB-цвета контуров |
| `output/facade_panel_320x200.svg` | SVG-превью с цветами слоёв |
| `output/preview.png` | Общий чертёж с миллиметровой сеткой и подсветкой слоёв |
| `output/simulation_full.png` | Симуляция гравировки лучом 0,2 мм на фоне ЛМДФ, весь светильник |
| `output/simulation_zoom.png` | То же, увеличенный фрагмент (контроль слияния линий) |
| `scripts/generate_facade.py` | Генератор геометрии + технологический аудит зазоров + экспорт |
| `scripts/render_simulation.py` | Рендер симуляции луча из итогового DXF |

## Слои и цвета (два цвета контуров)

| Слой DXF | Цвет ACI | RGB в EPS/SVG | Содержимое |
|---|---|---|---|
| `KONTUR` | 1 (красный) | `#e60d0d` | несущие контуры: рамы окон и дверей, межпанельные швы, плиты перекрытий, парапеты, корпуса кондиционеров, рамка поля |
| `DETALI` | 5 (синий) | `#0d33d9` | фактура: плитка стен, раскладка створок, отливы, решётки ограждений, трубы и вентиляторы кондиционеров |

В постпроцессоре лазера слоям можно назначить разную мощность/число проходов
(например, `KONTUR` — глубокий проход, `DETALI` — лёгкий).

## Размеры и масштаб

- Поле гравировки: **308×188 мм** с равным полем 6 мм внутри плиты 320×200 мм.
- Масштаб архитектурный, примерно **1:100** — пропорции взяты от реальных
  размеров, а не подогнаны под лист:

| Элемент | На макете | В натуре (≈) |
|---|---|---|
| Шаг этажа | 26,86 мм | 2,7 м |
| Оконный блок (двойная полоса) | 11,6 × 15,1 мм | 1,16 × 1,51 м |
| Одинарное окно | 13,0 × 15,1 мм | 1,3 × 1,5 м |
| Высота подоконной части | 8,5 мм | 0,85 м |
| Остекление балкона | 20 × 18 мм | 2,0 × 1,8 м |
| Дверь лоджии | 7,5 × 16,5 мм | 0,75 × 1,65 м |
| Плитка стен, шаг | 3,0 мм | 300 мм |
| Наружный блок кондиционера | 4,4 × 2,8 мм | 440 × 280 мм |

Состав фасада (слева направо): узкая секция одинарных окон, две секции
балконов с остеклением и сплошным парапетом, три секции парных окон, полоса
сплошного остекления с плиточным фартуком, ещё три секции парных окон,
секция утопленных лоджий. 8 блоков кондиционеров расставлены нерегулярно,
как на реальном фасаде.

## Технологические допуски под луч 0,2 мм

1. **Минимальный зазор между разноимёнными векторами — 0,30 мм**
   (т.е. центр одного луча не подходит к центру другого ближе 0,30 мм;
   при пятне 0,2 мм между прожжёнными бороздами остаётся перемычка ≥0,10 мм).
2. Плиточная сетка стен программно клиппингуется по всем проёмам
   (окна, балконы, фартуки, кондиционеры) с отступом 0,30 мм — линии
   не заходят на рамы и корпуса.
3. Двойные рамы окон разнесены на 0,9 мм, двойные линии отливов — на 0,7 мм.
4. Генератор завершается **аудитом зазоров**: точное попарное расстояние
   между отрезками (алгоритм Эриксона) с пространственной индексацией.
   Угловые пересечения (T-стыки, кресты, примыкания швов) разрешены —
   браком считаются только параллельные векторы с перекрытием >0,5 мм
   и зазором <0,30 мм, а также выход за габарит 320×200.
   Текущий результат: **0 нарушений, 0 выходов за габарит** (2268 примитивов).
5. DXF проходит встроенный аудит `ezdxf` без ошибок и исправлений.

## Перегенерация

```bash
python3 -m venv .venv
.venv/bin/pip install ezdxf matplotlib
.venv/bin/python scripts/generate_facade.py        # DXF/EPS/SVG/PNG + аудит
.venv/bin/python scripts/render_simulation.py      # симуляция луча 0,2 мм
```

## Рекомендации для производства

- Перед гравировкой проверить в CAM, что импортёр не масштабирует DXF
  (единицы — миллиметры, габарит примитивов 6…314 × 6…194).
- Сделать тестовый квадрат 50×50 мм на обрезке той же ЛМДФ и измерить
  фактическую ширину борозды; при отклонении от 0,2 мм пропорционально
  изменить `GAP_MIN` в скрипте и перегенерировать.
- Зеркаление не требуется: файл подготовлен в «прямом» виде, гравировка
  по лицевой стороне.
