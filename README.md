# Векторный макет фактуры панельного дома для светильника (4 стороны, 320×165 мм, ЛМДФ)

Лазерная гравировка фасада типовой панельной многоэтажки по приложенному
образцу. Генерация полностью параметрическая — все размеры в миллиметрах
задаются в начале `scripts/generate_facade_v2.py`.

## Файлы

| Файл | Назначение |
|---|---|
| `output/facade_side1_320x165.dxf` … `facade_side4_320x165.dxf` | **Отдельные DXF на каждую из 4 сторон**, габарит 320×165 мм, DXF R2010, единицы — мм |
| `output/facade_4sides_320x165.dxf` | Все 4 стороны на одном листе (раскладка 2×2, зазор 15 мм, лист 655×345 мм) |
| `output/facade_4sides_320x165.eps` | То же в EPS 3.0, координаты в мм, 8 RGB-цветов |
| `output/layout_colors.png` | Цветное превью листа 2×2 с подсветкой 8 классов объектов |
| `output/simulation_side.png` | Сторона 1: имитация гравировки лучом 0,2 мм на фоне ЛМДФ, масштаб 1:1 |
| `output/simulation_zoom.png` | Увеличенный фрагмент (кладка, рамы, кондиционер) — контроль слияния линий |
| `scripts/generate_facade_v2.py` | Генератор геометрии + технологический аудит + экспорт DXF/EPS |
| `scripts/render_simulation_v2.py` | Превью и симуляция луча из итоговых DXF |

Каждая сторона собрана со своим seed (101, 202, 303, 404) — рисунок
воспроизводимый, но расположение кондиционеров, стиль створок, трещины
и микро-дрожание линий у сторон разные, как на реальном здании.

## Состав и пропорции стороны 320×165 мм

Сверху вниз: **плоская крыша с парапетом** (техполоса 140–165 мм: парапет,
крышка, окна техэтажа, три вентшахты, у части сторон — антенна) →
**5 жилых этажей** по 25 мм (шаг ≈ 2,5 м в масштабе ~1:100) →
**цоколь на фундаменте** (0–15 мм: русты и три вентиляционные решётки).
На первом этаже в крайней секции — **подъезд с двойной дверью, козырьком
и двумя ступенями**.

Слева направо 10 секций: одинарные окна, две колонки балконов с парапетами,
три секции парных окон, полоса сплошного остекления с бетонным фартуком,
ещё три секции парных окон, утопленные лоджии (на 1-м этаже — подъезд).

| Элемент | На макете | В натуре (≈) |
|---|---|---|
| Шаг этажа | 25,0 мм | 2,5 м |
| Окно парной секции | 10,8 × 14,6 мм | 1,08 × 1,46 м |
| Одинарное окно | 12,8 × 14,6 мм | 1,28 × 1,46 м |
| Кирпич (ложок) | 4,2 × 1,8 мм | 250 × 65 мм (рядовой кирпич) |
| Кондиционер | 4,4 × 2,7 мм | 440 × 270 мм |
| Дверь подъезда | 11,0 × 16,9 мм | 1,1 × 1,7 м |

## Естественность линий и детализация

- Каждый вектор (кроме физической кромки панели) строится с детерминированным
  микро-дрожанием: синусоидальная волна + случайная компонента, концы линий
  зафиксированы. Прямые углы рам слегка «гуляют» — эффект ручной обводки,
  а не CAD-идеала.
- Вместо квадратной сетки — **настоящая ложковая кирпичная кладка**:
  горизонтальные ряды с шагом 1,8 мм и вертикальные швы со сдвигом в полкирпича
  на каждом втором ряду; кладка автоматически клиппингуется по проёмам
  (окна, балконы, кондиционеры, решётки цоколя).
- Добавлены: ручки створок, отливы, решётки парапетов, хомуты водостоков,
  вентиляторы кондиционеров с гибкой подводкой, русты цоколя, вентрешётки,
  козырёк и ступени подъезда, вентшахты и антенна на крыше, 2–3 диагональные
  трещины по свободным простенкам на каждой стороне.

## Технологические допуски (луч 0,2 мм)

- **Пересечения векторов разрешены** (T-стыки, кресты, примыкания швов).
- Аудит контролирует только то, что реально портит гравировку: **параллельные
  векторы с перекрытием > 0,5 мм на расстоянии менее 0,25 мм** — при пятне
  0,2 мм такие борозды сливаются в одну. Между любыми параллельными линиями
  гарантирован зазор ≥ 0,25 мм (двойные рамы — 0,9 мм, жилы водостока — 0,85 мм,
  кладка от проёмов — от 0,55 мм с запасом на дрожание).
- Точное попарное расстояние между отрезками (алгоритм Эриксона) с
  пространственной индексацией; результат по всем 4 сторонам:
  **0 параллельных слияний, 0 выходов за габарит 320×165**
  (~2 790 примитивов на сторону, 11 160 на листе).
- DXF проходит встроенный аудит `ezdxf` без ошибок; `$INSUNITS = 4` (мм).

## Перегенерация

```bash
python3 -m venv .venv
.venv/bin/pip install ezdxf matplotlib
.venv/bin/python scripts/generate_facade_v2.py       # 5 DXF + EPS + аудит
.venv/bin/python scripts/render_simulation_v2.py     # превью и симуляция луча
```

## Рекомендации для производства

- При импорте в CAM проверить, что DXF не масштабируется: единицы миллиметры,
  габарит каждого side-файла 0…320 × 0…165.
- Сделать тестовый квадрат 50×50 мм на обрезке той же ЛМДФ и измерить
  фактическую ширину борозды; при отклонении от 0,2 мм изменить
  `PARALLEL_MIN` в скрипте и перегенерировать.
- Файлы в «прямом» виде — гравировка по лицевой стороне, зеркаление не нужно.
- Для сборки коробки светильника стороны нумеруются side1…side4; сторона
  с подъездом у всех одинаково расположена внизу справа — удобно для
  выравнивания углов.
